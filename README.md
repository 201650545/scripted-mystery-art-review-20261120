# Scripted Mystery Art Review Source Pack

This public snapshot supplies the same source context to two independent visual-code reviews for the five-player LAN mystery game prototype.

## Included material

- `current-prototype/` contains the current waiting-room UI source, its prototype interaction code, the five-seat stage view, puppet model, and a sanitized project overview.
- `archive-reference/` contains the archived Weizhuo application sample source and stylesheet for typography, restrained borders, dark-layer hierarchy, spacing, and component weight.

The archive source is a design-language reference only. Do not reuse or reproduce any scene, image, screenshot, story, or character content referenced by the archived sample. The current puppet model in `current-prototype/puppet-model.js` and the current five-seat Western table are the only visual-model basis for the new preview.

The prototype overview was rewritten for external review to omit local machine paths and LAN addresses. No image files, audio files, credentials, environment files, or runtime data are included.

All source files are provided as a review snapshot. The review task must return isolated previews and minimal patches without changing this repository or the original project.
